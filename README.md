# Python_Task_Management_Summary_Script

## 📌 Project Overview

This project was developed as part of my AI and Automation course to practice Python programming fundamentals and understand how automation can simplify repetitive tasks.

The script manages a collection of tasks, identifies their completion status, generates a summary of pending and completed tasks, and automatically saves the report to a text file.


## 🎯 Project Objectives

- Store and manage tasks using Python data structures.

- Use loops to process multiple tasks.

- Apply conditional statements to classify tasks by status.

- Calculate the total number of tasks, pending tasks, and completed tasks.

- Generate and save a formatted summary using Python file handling.



## 🛠️ Technologies and Concepts Used

- Programming Language: Python

- Data Structures: Lists and Dictionaries

- Control Flow: Loops and Conditional Statements

- String Formatting: Formatted output using f-strings

- File Handling: Writing output to a .txt file

- Testing: Running the script and verifying the output


## ⚙️ How It Works

- The script stores six sample tasks, each with a task name and a status of Pending or Done.

- A loop iterates through the task list.

- Conditional statements classify tasks into pending and completed groups.

- The program calculates the total number of tasks in each category.

- A formatted summary is printed to the terminal.

- The same summary is written to task_summary.txt.
